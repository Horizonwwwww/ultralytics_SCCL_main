## 📖 项目简介

准确识别可回收废弃物是实现高效垃圾管理的关键。然而，现实场景中物体的**严重遮挡**、**几何形变**及**复杂堆叠**，导致现有轻量级模型漏检与误检率高。

为此，本研究旨在开发一种适用于**边缘计算**的高精度、高效率检测模型，以增强模型对复杂特征的判别力。我们提出了 **SCCL-YOLO11n**（Self-Calibrated Convolution & Convolutional Attention Fusion Lightweight YOLO11n），在 YOLO11n 架构基础上进行三大核心改进：

| 创新模块 | 核心作用 |
|:---:|---|
| 🔧 **SCConv**<br>自校准卷积模块 | 自适应增强多尺度特征表达，提升对不同尺寸目标的感知能力 |
| 🎯 **C2DA**<br>可变形双注意力模块 | 使模型聚焦于非刚性目标轮廓，精准捕获几何形变特征 |
| 🔗 **CAFM**<br>卷积与注意力融合模块 | 协同捕获局部细节与全局上下文依赖，提升对变形目标的建模能力与遮挡上下文感知 |
| 🚀 **LSCD**<br>轻量级共享卷积检测头 | 在显著降低计算量的同时保持高精度检测 |

> **S**elf-**C**alibrated **C**onvolution & **C**onvolutional **L**ightweight **YOLO11n**

在包含 **5,383 张图像**的自建数据集上，该模型以仅 **6.1 GFLOPs** 的计算量实现 **96.3% mAP**，在遮挡、重叠与变形目标场景中均表现出优异鲁棒性，综合性能优于当前主流轻量模型。

### 四大创新模块详解

#### 🔧 SCConv — 自校准卷积模块
> **Self-Calibrated Convolution Module**

- 通过自校准机制自适应调整卷积核权重
- 多尺度特征增强，有效应对目标尺寸差异
- 嵌入 Backbone，提升基础特征提取质量

#### 🎯 C2DA — 可变形双注意力模块
> **Deformable Attention-based Dual Attention Module**

- 基于可变形注意力机制，突破常规网格采样限制
- 聚焦非刚性目标轮廓，精准建模几何形变
- 双注意力协同，兼顾通道与空间维度的重要性建模

#### 🔗 CAFM — 卷积与注意力融合模块
> **Convolution and Attention Fusion Module**

- 卷积分支捕获局部细节特征
- 注意力分支建模全局上下文依赖
- 双分支协同融合，提升对变形目标的建模能力与遮挡上下文感知

#### 🚀 LSCD — 轻量级共享卷积检测头
> **Lightweight Shared Convolutional Detection Head**

- 共享卷积参数，大幅削减检测头计算量
- 保持多尺度检测精度，兼顾效率与性能
- 专为边缘端部署优化
